# Structured-Credit-projects

This project is final project of IE598 Structued Credit in UIUC MSFE, instructed by Mr. Ishan Prasad @Figure. In this project, we explored the evaluation of MBS, including structured product cashflow amoritization, prepayment modeling and default modeling.

All files contains:

default modeling.ipynb: Modeling of single loan default rate using Logistic regression and Random Forest

Default_project: html version of code and explaination

Prepayment modeling.ipynb: Modeling of prepayment rate (SMM)

Prepayment_Code_and_Summary.html: html version of code and explaination
